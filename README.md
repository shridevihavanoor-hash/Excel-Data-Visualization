# Excel Data Visualization – Sales Analysis

## Project Overview
This project demonstrates my practical skills in Microsoft Excel through sales data analysis, charts, formulas, and Pivot Tables.

The dataset contains sales and profit information for three products across four regions over six months.

## Tools and Skills Used
- Microsoft Excel
- SUMIF and SUM formulas
- Percentage calculations
- Bar and Column Charts
- Pie Charts
- Line Charts
- Scatter Plots
- Pivot Tables

## Visualizations Created
1. **Monthly Sales Bar Chart:** Compares monthly sales from January to June.
2. **Product Profit Comparison:** Compares total profits for three products.
3. **Sales by Region Pie Chart:** Displays regional sales contributions as percentages.
4. **Monthly Sales Trend:** Shows changes in sales over six months.
5. **Sales vs Profit Scatter Plot:** Examines the relationship between sales and profit.
6. **Pivot Table:** Summarises total sales by region.

## Key Findings

| Metric | Result |
|---|---|
| Total Sales | 39,000 |
| Total Profit | 16,500 |
| Highest Sales Month | June (9,000) |
